WebShop Manager
Автор: Султанов Нурлан Дата создания: МАЙ 2026

Описание
WebShop Manager — это десктопное GUI-приложение для управления каталогом товаров в веб-магазине. Позволяет просматривать, искать, добавлять, редактировать и удалять товары, а также сохранять данные в локальном JSON-файле. Упрощает работу менеджера интернет-магазина без необходимости заходить в админку сайта.

Основные возможности
🔍 Поиск товаров по названию, категории или артикулу
📋 Отображение списка товаров с ценой, остатком и рейтингом
➕ Добавление нового товара (название, цена, категория, количество)
✏️ Редактирование существующего товара (изменение цены, описания, остатка)
❌ Удаление товаров из каталога
💾 Автосохранение каталога в JSON-файл (при каждом изменении)
📊 Фильтрация по категориям и ценовым диапазонам
🖨️ Экспорт каталога в CSV или HTML-отчёт

Требования

**Python 3.7+
Библиотеки:
tkinter (встроенная)
json (встроенная)
Pillow (опционально, для работы с изображениями товаров)
Установка и запуск

Примеры запуска для разных операционных систем

Windows

 1. Откройте командную строку (cmd) или PowerShell
 2. Перейдите в папку с проектом
cd C:\Users\YourName\webshop_manager

 3. Установите зависимости (только при первом запуске)
pip install pillow

 4. Запустите приложение
python main.py

 Альтернативный запуск (если не работает python)
py main.py

 Запуск с указанием конкретной версии Python
py -3.11 main.py
macOS / Linux

 1. Откройте терминал
 2. Перейдите в папку проекта
cd /home/user/webshop_manager

 3. Установите зависимости
pip3 install pillow

 4. Запустите приложение
python3 main.py
Пример работы

При запуске открывается главное окно со списком товаров.
В поле поиска вводите «смартфон» – список фильтруется.
Нажимаете «Добавить товар» – появляется форма, заполняете поля (название, цена 19999, категория «Электроника», остаток 5).
После сохранения товар появляется в общем списке и автоматически записывается в catalog.json.
Выделяете товар и нажимаете «Редактировать» – меняете цену, изменения сразу сохраняются.
Кнопка «Экспорт в CSV» создаёт файл catalog_export.csv с текущим каталогом.
